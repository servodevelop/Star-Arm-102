# 102-LD/HD → 102-FL Python control

[← Python SDK](../README.md) | <sub>**English** / [简体中文](README.zh.md)</sub>

Use a 102-LD or 102-HD leader to control a 102-FL follower. Choose the number of leader–follower pairs:

| Control mode | Hardware required | Start here |
| --- | --- | --- |
| Single pair (1-to-1) | 1 leader + 1 follower; 2 arms total | [Single-pair guide](single-pair/README.md) |
| Dual pair (2-to-2) | 2 leaders + 2 followers; 4 arms total | [Dual-pair guide](dual-pair/README.md) |

Each guide contains its complete installation steps, operating commands, behavior, and validation scope. In dual-pair mode, leader 1 controls follower 1 and leader 2 controls follower 2. Keep the scripts together in their mode directory and follow that guide's working-directory instructions.
