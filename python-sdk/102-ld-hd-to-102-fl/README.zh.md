# 102-LD/HD → 102-FL Python 控制

[← Python SDK](../README.zh.md) | <sub>[English](README.md) / **简体中文**</sub>

使用 102-LD 或 102-HD 主臂控制 102-FL 从臂。按主从臂组数选择：

| 控制方式 | 所需设备 | 从这里开始 |
| --- | --- | --- |
| 单组主从臂（1 控 1） | 1 台主臂＋1 台从臂，共 2 台 | [单组使用指南](single-pair/README.zh.md) |
| 双组主从臂（2 控 2） | 2 台主臂＋2 台从臂，共 4 台 | [双组使用指南](dual-pair/README.zh.md) |

各指南均保留完整的安装步骤、操作命令、功能行为及验证范围。双组模式下，主臂 1 控制从臂 1，主臂 2 控制从臂 2。请将脚本保留在对应模式目录内，并按指南指定的工作目录执行。
