# vla-arms-agent

← [Star Arm 102](../README.zh.md) · <sub>[English](README.md) / **简体中文**</sub>

[源码仓库](https://github.com/servodevelop/Star-Arm-102/tree/main/vla)

**用自然语言，让机械臂看见物体、完成抓取与放置。**

vla-arms-agent 是面向 Star Arm 102-FL 从臂的 AI 机械臂工作台。连接机械臂、外部摄像头和腕部摄像头后，在网页中输入任务，AI 就能结合画面与电机反馈，调整夹爪、抓起物体，并将它放到指定区域。

> 把海绵移动到中心框，再放到红色框；如果已经在中心框，就直接放到红色框。

任务对话、实时画面、机械臂姿态和执行过程集中在同一个页面。你可以观察 AI 的操作，随时补充要求，或通过手动控制探索每个关节的运动。

## 从一句话到一次完整抓放

AI 会围绕任务持续观察和调整，把一次抓放分成几个清楚的步骤：

1. **看清目标。** 外部相机观察整个桌面，腕部相机看清夹爪附近的物体。
2. **确定抓取位置。** 结合外部与腕部画面确定位置、姿态和开口。需要时通过接触辅助定位，撤离后准备抓取。
3. **充分夹住物体。** 张开夹爪、接近物体，用新画面检查夹持位置、姿态和深度，再闭合、抬起，观察物体是否随夹爪移动。
4. **搬运并放置。** 将物体移到指定区域，放低、松开，撤离后检查落点。
5. **回到工作位。** 完成任务后返回预设姿态，闭合夹爪，并查看最终画面。

抓取中的方向调整、有效位置和你的补充会保留在当前会话中，供后续操作继续使用。对于已经确定的连续动作，AI 可以一次完成“夹紧后抬升”或“释放后撤离”，减少等待回合。

## 一个页面，完成观察与控制

### AI 任务与对话

用日常语言描述目标、位置和操作顺序。AI 通过相机观察现场，读取机械臂状态，再调用运动和夹爪工具执行任务。

- **连续任务：** 先放到一个区域，再搬到另一个区域。
- **过程补充：** 运行中发送“目标在左边”“换腕部视角看一下”等提醒。
- **实时进度：** 查看模型回复、当前工具和执行结果，展开详情了解具体动作。
- **模型选择：** 配置 AI 服务、模型名称与思考强度，模型支持列表选择和手动输入。
- **会话延续：** 沿用已有观察、动作结果和调整经验，接着完成后续操作。

### 外部与腕部两个视角

| 相机 | 主要用途 | 摆放方式 |
| --- | --- | --- |
| 外部相机 | 找到物体、目标区域，观察搬运与落点 | 覆盖整个工作桌面 |
| 腕部相机 | 看清夹爪与物体的距离、方向和接触位置 | 固定在腕部，朝向夹爪附近 |

两路相机分别绑定、分别预览。页面提供 **720p / 1080p** 和 **30 / 60 FPS** 选项，并显示设备当前采用的采集配置。

相机支持同时采集和轮流采集。多台相机共享 USB 连接时，轮流使用两路画面有助于减轻带宽占用。AI 可以在取图时完成相机切换，运动结束后直接获取新的观察画面。

### 先预览，再执行

手动控制适合熟悉机械臂、调整姿态和观察动作效果。

- 编辑六个关节的目标角度，点击“预览目标”，对比当前姿态与预计结束姿态。
- 切换空间、侧视、俯视，观察关节与末端的位置关系。
- 点击“执行关节目标”，让机械臂移动到选定姿态。
- 调整夹爪开口，选择适合物体宽度的张开角度。
- 点击“回工作位”，让六轴与夹爪同步返回预设姿态，夹爪默认闭合。

希望按位置移动时，可以输入末端的目标坐标，由位置求解生成一组关节方案，再预览并执行。

### 看见机械臂的实际状态

工作台持续读取电机反馈，展示实际关节角、夹爪开口、电流、电压和功率。姿态预览和实际回读分别呈现，方便对照目标与动作结果。

任务需要暂停时，点击“停止 AI 与运动”，系统会取消后续调用，让舵机保持当前位置和夹爪状态。模型连接遇到短暂波动时，会自动重试，并在会话中显示进度。

## 开始前，准备这些

| 准备项 | 说明 |
| --- | --- |
| Star Arm 102-FL 从臂 | 实际执行动作的机械臂，以及夹爪、电源和 USB 串口连接线 |
| 两个普通 USB 摄像头 | 分别用作外部相机和腕部相机 |
| 一台电脑 | 安装 Docker，使用 Chrome 或 Edge 打开工作台 |
| 一个视觉 AI 服务 | 支持图片理解、工具调用和 OpenAI Responses 接口，准备好 API 地址、密钥及模型名称 |
| 一个桌面场景 | 放置容易辨认的物体，并用清晰标记指定目标区域 |

首次使用可以从海绵等轻小物体开始，熟悉相机观察、夹爪开口和放置流程。

机械臂和相机连接到**运行浏览器的电脑**。Docker 提供网页访问入口，浏览器直接完成设备连接与控制。

## 开始使用

### 1. 启动工作台

在 Star-Arm-102 仓库根目录运行：

```sh
cd vla
docker compose up -d --build
```

容器会完成网页构建并启动 Next.js 服务。用 Chrome 或 Edge 打开 **[http://localhost:8780](http://localhost:8780)**。

### 2. 连接机械臂和相机

在“连接与观察”区域：

1. 点击“选择串口并连接”，在浏览器弹窗中选择机械臂的 USB 串口。
2. 点击任一相机卡片“绑定设备”旁的“授权 / 刷新”，在 Chrome 中允许摄像头访问，再分别选择外部相机和腕部相机。摄像头授权无需先连接从臂。
3. 开启预览，确认两路画面对应正确的安装位置，选择分辨率和帧率。
4. 点击“保存配置”，保留设备绑定。

两台相机名称相同时，分别开启单路预览，就能确认各自对应的视角。
完成连接后，可点击“连接与观察”标题收起该区域，相机和机械臂继续保持连接。操作结果与错误显示在窗口底部。

### 3. 连接 AI

展开“模型与动作配置”，填写 AI 服务的地址、API Key 和模型名称，选择思考强度与服务档位，再点击“验证连接与能力”。开启相机后，验证过程会使用一张当前画面检查识图能力。

服务档位默认为“自动”。Fast、Ultrafast 用于更快且费用更高的处理；“标准”使用标准档位，Priority 适配较旧的兼容接口，Flex 更省费用但可能更慢。点击“保存 AI 配置”保留选择。档位需要所选模型和接口支持，页面会显示最近任务请求的服务端回显档位。

任务指令和使用到的画面会发送到你配置的 AI 服务。API Key 随配置保存在当前浏览器，刷新后自动恢复；清空后保存即可清除。

### 4. 发出第一个任务

先让 AI 观察场景：

> 看看两路相机中的物体，描述一下海绵和目标区域的位置。

再发送抓放任务：

> 把海绵移动到中心框，再放到红色框；如果已经在中心框，就直接放到红色框。

点击“开始会话”发送任务。已有会话中，点击“追加对话”并确认后继续沟通；新任务建议先点击“新会话”。

你可以在运行中继续补充：

> 夹取前看一下腕部画面，把夹爪对准海绵中部。

AI 会从当前进度继续处理。开启外部相机预览后，任务会附带一张外部当前画面，减少等待取图的往返。运动结束后默认附带外部与腕部两张新图，AI 可选择不附图。带宽受限时轮流取图，连续动作序列只在结束时取图。长对话使用模型原生上下文压缩，配置中显示最近请求的响应时间与缓存命中率。模型与动作配置、任务提示位于输入框上方。下方按时间正序展示回复与执行流程，具体步骤可展开查看详情；滚动到流程末尾后可继续向下浏览页面。完成后，可以从最终画面、关节状态和工具记录中查看结果。

## 界面语言

通过顶部 **English / 简体中文** 选择器切换界面，浏览器会保存选择。新一轮 AI 使用对应语言的指令和说明；已有用户消息和模型回复保留原文。运行中切换不会改变当前轮次的指令或设备连接。

## 保存设置，继续使用

在“模型与动作配置”中点击“保存 AI 配置”，即可记住 API Key、模型和动作参数。设备区的“保存配置”保留相机绑定和控制参数；设置均保存在当前浏览器中，任务对话自动保存。

刷新页面后，连接串口并开启相机预览，就可以接着历史会话使用。点击“新会话”开始一段新的任务对话。
刷新前未完成的任务会标记为中断，保留已经发送的补充；重新连接后发送“继续”，AI 会先检查实际状态。
