## Choose a tool

For third-party follower setups, see [cross-brand pairing resources](../integrations/README.md).


Choose a tool below, then follow its Wiki guide to launch the web interface or download the desktop software. The Wiki maintains current versions, compatibility details, and step-by-step instructions.

| Tool | Use it for | Guide and tool entry |
| --- | --- | --- |
| Star Arm 102 web control | LD / HD leader and FL follower connection, teleoperation, 3D pose display, and configuration | [Robot arm web control guide](https://fashionstar.com.hk/wiki/software/robot-arm/web-config-tool/) |

## Before connecting

Read the tool's connection requirements and the [hardware setup guide](../docs/getting-started.md#connect). The web tools recommend Chrome or Edge with Web Serial support. Check the servo model, protocol, adapter, and power supply before choosing a servo tool.

Tool applications, installers, and their dependencies are maintained outside this repository. This directory contains navigation only. Repository maintenance scripts are in [scripts](../scripts/README.md).
